# Kantai

「蒼海の盾」。海が地表の大半を占める架空の惑星ペラギアで、一国の守りと舵取りを預かるブラウザゲームです。世界情勢を読み、外交と国政を進め、艦隊・航空部隊・陸上部隊を配置し、海戦・空の対処・地上戦を指揮します。
`index.html` 1ファイルで動きます。国・海・島・艦・人・装備の名前はすべて架空です。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。GitHub Pages を有効にすると、
`https://kamamon.github.io/Kantai/` で公開されます(Settings → Pages → Branch を `main` / `/(root)`)。

進行はブラウザに自動で保存されます。

## 内容

- **世界地図**：惑星ペラギアを1枚の地図として生成する。陸は45か国・246州・約1,700のプロヴィンスに、海は約100の海域に分かれる。地形(平地・森林・密林・丘陵・山岳・砂漠・雪原)、河川、州ごとの都市がある
  - 作戦図も世界地図も、＋－のボタンか2本指で拡大でき、指で動かせる。拡大すると州境、プロヴィンスの境、河川、都市の名が現れる。作戦図を拡大すると艦隊の内訳が出る
  - 地図の種類を切り替えられる：政治(国)、陣営、自国との関係、地形、州、開発度。土地をタップすると、州と持ち主がわかる
- **世界情勢**：45か国は「環洋条約機構」「大陸協商」と非同盟に分かれ、それぞれに政体と首脳がいる
  - 国境の火種が戦争になり、プロヴィンスが1つずつ奪われて前線が動く。首都が落ちれば降伏し、併合される国も出る。政変、陣営の出入り、選挙も起こる
  - 対峙する国が戦争を始めればこちらへの圧力は弱まり、勝てば国力を増す。毎月のニュースと、年に一度の情勢報告で追える
  - 難民船、支援の要請、諜報員の拘束、軍縮会議、亡命の申し出など、選択を迫られる出来事が起こる
- **本土への侵攻**：陸で接する国は、自国にも攻め込んでくる(国政 → 国防)
  - 国境ごとに緊張があり、関係が悪く、こちらの守りが薄いほど上がる。兵力の集結、国境危機の出来事と段階を踏み、85を超えると、勝てると見た相手は国境を越える
  - 本土の防衛力は、本土にいる陸上部隊、兵役の政策と基地(郷土防衛隊)、本土の飛行隊、同じ陣営と防衛協力の国、国境の地形で決まる。相手の兵力を上回っていれば、相手は踏み切れない
  - 開戦すると、前線の戦いはプロヴィンスごとに行う。敵は兵力差に応じて毎月0〜3か所へ攻めかかり、そのつど「自ら指揮する・任せる・明け渡す」を選ぶ(前線の戦いをまとめて任せることもできる)
  - こちらからも月に3回まで進攻できる。国防の一覧か世界地図でプロヴィンスを選び、投入する部隊(5個まで)を決めて、自ら指揮するか参謀に任せる。戦場に出さない特科・ロケットの部隊は後方から支援射撃をする
  - 構え(持久防御・機動防御・反攻)は、参謀が自分から進攻するかどうかと、任せた戦いの戦い方を決める。相手は損害と補給線の伸びで息切れする
  - 本土の戦いで戦力が尽きた部隊は消えずに潰走し、戦力1で後方へ下がる。戦わなかった月は通常どおり回復する
  - 州の中心都市と首都の戦いは、任せていても必ず判断を求められる
  - 中心都市を失った州は経済から外れ、GDPと防衛予算が減る。**首都が落ちれば、任期はそこで終わる**
  - 緊急動員、停戦の申し入れ、講和(原状回復・割譲・賠償)、不可侵条約、割譲した土地を取り戻す戦いがある。反攻で相手の首都を落とせば降伏させられる
  - 陸で接する国がない島国(45か国のうち3か国)は、陸からは攻め込まれない
- **陸上部隊の編成**：中隊を並べた編成表から連隊を作る(部隊 → 編成表)
  - 主力は8個まで(普通科・機械化・戦車・機動戦闘車・水陸機動・空挺・特科・ロケット・高射・地対艦ミサイル)、支援隊は3個まで(施設・重迫撃砲・対戦車・近距離防空・偵察・後方支援)
  - 攻撃・防御・移動・調達費・維持費が編成から決まる。規模が大きいほど強く、高い。主力の半分以上は、その兵科の中隊にする
  - 編成表を作っておくと、その編成で新しい部隊を調達でき、本土にいる部隊を改編できる。編成表を改めると、使っている部隊がまとめて改編される
- **基地の整備**：本土と3つの島それぞれに、港湾と飛行場を5段階まで広げ、対空・対艦ミサイル基地を3基まで置ける(部隊 → 基地)
  - 港湾は、島では整備度の低下を抑えられる艦の数、本土では同時にドックへ入れられる艦の数を増やす。飛行場は置ける飛行隊を増やす
  - ミサイル基地は海戦に陸上の拠点として加わり、空襲と上陸も妨げる。島を奪われると失われる
- **防衛産業**：造船・航空機・誘導武器・電子・車両と火砲・素材の6社を育てる(国政 → 産業)。発注と輸出で経験を積み、国庫からの投資で早められる。段階が上がるほど、価格・建造期間・戦力などに効く
- **ドクトリン**：海上・航空・陸上のそれぞれで1つ選ぶ(国政 → 国防)。選んだ直後は効果が4割で、20か月かけて満額になる
- **貿易**：資源ごとに、国庫での買い付け、備蓄の目標、輸出の量と売り先(誰にでも・友好国だけ・自陣営だけ)を決める(国政 → 貿易)
- **武器の輸出**：輸出の方針(禁輸・同盟と友好国のみ・紛争当事国を除く・制限なし)と売ってよい品目を決め、届いた引き合いを1件ずつ受けるか断る。契約のあいだ毎月国庫に入り、企業が育ち、相手国との関係がよくなる
- **外交**：政治力を使って、関係の改善、通商協定、防衛協力、不可侵条約、軍事援助、和平の仲介、経済制裁、相手国との首脳会談ができる
- **国政**：
  - 国家方針：軍事・外交・産業・政治・科学の5系統36項目のツリー。一度にひとつ進め、分かれ道(同盟加盟か中立か独自の協約か、など)では片方しか選べない
  - 政策：防衛方針、兵役、経済体制、貿易、情報と報道、防衛費の水準。各勢力(財界・軍部・労働界・地方・学術界)の満足と安定度に響く
  - 顧問の登用、4年ごとの総選挙と与党の交代
  - 州の開発：州ごとに人口・開発度・資源があり、国庫で開発度を上げ、工業地帯・港湾・造船所・研究拠点などを建てる。GDPが伸びると年度の防衛予算も増える
  - 資源：石油・鋼材・希少金属・食料。足りない分は通商協定の相手から輸入し、航路が妨害されると細る
- **45の国から選ぶ**：世界地図か一覧で国をタップすると情報が開き、「戻る」で選択に帰る。対峙する国も選べる。国ごとに名称群が丸ごと変わる
  - 艦名・人名・海域と島の名・装備6種の名(戦闘機、警戒機、SAM、SSM、AAM、魚雷)
  - 艦種の呼び方4系統(護衛艦式・駆逐艦式・巡洋艦式・フリゲート式)、陸上部隊の呼び方3系統、階級と人事用語3系統、艦隊名の付け方
  - 国柄(小さな得意分野)。たとえば建造が速い、潜水艦が静か、陸上部隊が強い、など
  - 装備の型。戦闘機・警戒機・SAM・SSM・AAM・魚雷のそれぞれに、長射程型・大威力型などの型があり、長所と短所が能力に反映される
- **プレイ中の編集**：「概況」の編集から、遊びながら数値を書き換えられる。装備の名前と型、能力の補正、艦種と陸上部隊の基準値、研究の段階、開発計画の完了、資金・支持率・在庫など。編集を使った記録は、任期の結果にその旨が出る
- **装備の諸元**：国を選ぶ画面と「部隊」の装備で、装備ごとの能力(射程・命中率・搭載数など)と、艦種・陸上部隊の能力を見られる
- **装備の世代**：戦闘機・爆撃機・哨戒ヘリ・艦対空/艦対艦/空対空ミサイル・魚雷・艦砲・近接防御・レーダー・ソナー・電子戦・戦車・火砲・衛星など44系列に、旧式(G1)から現用(G4)、開発中・構想中(G6〜G7)まで289機種がある
  - 例：機関砲 → 赤外線誘導AAM → アクティブ中距離AAM → 超長射程AAM、高射機関砲 → 多銃身機関砲 → 高出力レーザー → 高出力マイクロ波
  - 国ごとに得手不得手があり、開始時の機種が系列ごとに1世代ずれる。研究を進めて次の機種を開発すると全軍に行き渡る
  - カスタムスタートで、旧式・ひと昔前・現用・新鋭のどの時代から始めるかを選べる
- **艦種**：35種。砲と爆雷の旧式護衛艦、ミサイル艇、対潜護衛艦、ヘリコプター護衛艦、コルベット、ミサイル巡洋艦、ドック型輸送艦から、原子力潜水艦、原子力空母、ミサイル防衛艦、さらに各国で計画・構想中のアーセナル艦、無人機母艦、大型無人水上艦、超大型無人潜水艇、電磁加速砲を積む次々世代艦まで
- **航空部隊**：戦闘・攻撃・爆撃・警戒・哨戒・電子戦・空中給油・輸送・無人偵察の9種の飛行隊を、本土と島の飛行場に置く
  - **緊急発進(スクランブル)**：国籍不明機が近づくと、届く戦闘飛行隊が上がる。届かなければ取り逃がし、支持率に響く。ときどき自分で指揮する事案になり、戦闘機を寄せて警告し、領空から去らせる
  - 受け持つ海域の海戦には、基地から戦闘機と攻撃機を出せる。警戒機・哨戒機・電子戦機・無人機は探知や妨害で支える
  - 哨戒航空隊は、海戦で基地から哨戒機を上げられる。対艦ミサイルと短魚雷を積み、ソノブイで潜水艦を探す。積めるものは哨戒機の世代で変わる
  - 警告は航空機からも出せる(相手の25km以内)。艦がいない海域の事案にも、哨戒機か攻撃飛行隊が届けば航空機だけで出られる
  - 輸送航空隊は陸上部隊を空輸し、爆撃・攻撃飛行隊は占領された島や敵の泊地を叩ける(侵攻の兆しがないときの泊地攻撃は、先制攻撃として強く非難される)
- **広域の作戦**：作戦図は世界地図から自国のまわりを切り出したもの。本土近海と、近い7つの海域に艦隊を編成して送る。海域のつながりは国の位置で変わる
  - 艦隊は1か月に2海域ぶん進む。事案にはその海域の艦隊が当たり、隣と2つ先の海域からは増援が遅れて着く
  - 守る島は、本土から離れた3つの海域に1つずつ。シーレーンを空けたままにすると通商妨害で収入が減る
  - 敵の揚陸部隊は泊地に集結してから出撃する。察知できれば、艦隊を回して迎え撃てる
- **海戦**：リアルタイム(一時停止と ×1〜×16)。2Dの戦術図と、視点を回せる3Dビュー。島のレーダーサイトや地対艦ミサイル連隊、航空基地も戦闘に加わる
  - 戦術図の艦と航空機は、進む向きを向いたシルエットで描く(艦・空母・揚陸艦・潜水艦・戦闘機・大型機・無人機)。大きく拡大できる
- **専守防衛**：敵が撃つか領海に居座るまで武器は使えない。50km以内に寄せて警告し、退去させるのが最良
- **地上戦**：ターン制。9×11マスの島で、砂浜・森・丘・市街と6種の施設(司令部・飛行場・港湾・レーダーサイト・補給処・市街)をめぐって戦う
  - 陸上部隊は9種(水陸機動・空挺・普通科・戦車・攻撃ヘリ・特科・多連装ロケット・高射・地対艦)。輸送艦に乗せるか、輸送航空隊で空輸して島へ運ぶ
  - 空挺と攻撃ヘリは、奪還のとき浜以外にも降りられる。緊張が高いと、敵の特殊部隊が潜水艦から島を襲うことがある
  - 敵に上陸されると守備隊が迎え撃つ。守備隊がいなければ無抵抗で占領される
  - 奪還は、制海戦闘 → 準備攻撃(艦砲射撃・空爆・ミサイル) → 上陸作戦 の順。制海を保つと封鎖で敵が弱る
  - 戦闘中も、その海域の艦隊が艦砲射撃・爆撃・ミサイルで支援する
- **司令部**：作戦、部隊(艦艇・艦隊編成・陸上部隊)、調達、人事、開発、予算
  - 開発：16分野・160系統・各10段階の研究(陸上装備・航空作戦・宇宙サイバー・先進技術を含む)、研究所10種、装備の世代交代、新艦種の開発、改修キット
  - 予算：9分野64費目、年度替わりの増額折衝、補正予算、分割払い、台帳
  - 人事：組織図(司令 → 司令部 → 艦隊 → 艦 → 幹部、航空部隊、基地、学校、研究所)の枠をタップして任命する。昇任・課程派遣、曹士15職種の充足と技能
  - 国政：情勢・外交・国防・方針・政策・内政・産業・貿易
- **カスタムスタート**：任期5〜30年、敵の強さ、陸からの侵攻の有無、予算、初期の艦隊・航空部隊・陸上部隊、装備の世代、技術水準などを設定できる
- **図上演習**：海戦・上陸戦・緊急発進を、情勢に影響なく練習できる

## 作り

```
index.html      ゲーム本体(これだけで動く)
src/            index.html のもとになる部品
  base.html     画面の土台と海戦の中核
  data2.js      海域・艦種・陸上部隊・研究・予算・人事のデータ
  nations.js    45か国の名称群テンプレート、装備の型と諸元、用語の言い換え
  equip.js      装備体系(世代つきの機種)、追加の研究分野・艦種・航空部隊・陸上部隊
  world.js      世界地図の生成(領土・州・プロヴィンス・地形・河川・海域)、作戦海域の割り当て
  mapview.js    地図の描画(プロヴィンス単位の塗り分け、境界線、地図の種類)、拡大と移動
  sym.js        艦と航空機のシルエット
  state2.js     状態と人事・研究の月次処理
  hq2a.js       画面の共通部品、タイトル、カスタムスタート
  hq2b.js       人事・開発・予算の画面と操作
  equip_ui.js   装備体系の画面
  org.js        組織図
  theater.js    海域・艦隊・島・陸上部隊と、月の進行
  theater_ui.js 作戦図と部隊・調達の画面、艦隊と陸上部隊の操作
  editor.js     プレイ中の編集(装備・艦種・陸上部隊・研究・能力補正)
  air.js        航空部隊、緊急発進、基地航空の海戦参加、空輸、泊地攻撃
  polity.js     世界情勢(陣営・戦争・政変)、国家方針、政策、顧問、選挙、州の経済と資源、出来事
  polity_ui.js  国政の画面(情勢・外交・方針・政策・内政)
  landwar.js    本土への陸からの侵攻(国境の緊張、プロヴィンスごとの進攻と防御、講和)と国防の画面
  base.js       基地の整備(港湾・飛行場・対空/対艦ミサイル基地)
  army.js       陸上部隊の編成表と編成画面
  econ2.js      防衛産業、ドクトリン、資源の貿易、武器の輸出
  battle2.js    海戦の部隊生成と兵装
  ground.js     地上戦
  view3d.js     3Dビューと入力
  css_add.css   追加のスタイル
  build.py      部品を1ファイルに組み立てる
```

部品を直したら、リポジトリの直下で次を実行すると `index.html` が作り直されます。

```
python3 src/build.py
```
