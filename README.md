# Kantai

「蒼海の盾 ― 機動護衛群司令部」。現代の海で、艦隊の戦闘指揮と運営を担うブラウザゲームです。
`index.html` 1ファイルで動きます。国名・艦名・人名はすべて架空です。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。GitHub Pages を有効にすると、
`https://kamamon.github.io/Kantai/` で公開されます(Settings → Pages → Branch を `main` / `/(root)`)。

進行はブラウザに自動で保存されます。

## 内容

- **戦闘**：リアルタイム(一時停止と ×1〜×16)。2Dの戦術図と、視点を回せる3Dビューを切り替えられる
- **専守防衛**：敵が撃つか領海に居座るまで武器は使えない。50km以内に寄せて警告し、退去させるのが最良
- **司令部**：配置、部隊(演習・整備・改修)、調達、人事、開発、予算
  - 開発：12分野・120系統・各10段階の研究、研究所8か所、装備開発計画28件、改修キット11種
  - 予算：9分野64費目、年度替わりの増額折衝、補正予算、分割払い、台帳
  - 人事：幹部の補職・昇任・課程派遣、曹士14職種の充足と技能
- **カスタムスタート**：任期5〜30年、敵の強さ、予算、初期艦隊、技術水準などを設定できる

## 作り

```
index.html      ゲーム本体(これだけで動く)
src/            index.html のもとになる部品
  base.html     画面の土台と戦闘の中核
  data2.js      艦種・研究・予算・人事のデータ
  state2.js     状態と月次の処理
  hq2a.js       司令部の画面、タイトル、カスタムスタート
  hq2b.js       人事・開発・予算の画面と操作
  battle2.js    戦闘の部隊生成と兵装
  view3d.js     3Dビューと入力
  css_add.css   追加のスタイル
  build.py      部品を1ファイルに組み立てる
```

部品を直したら、リポジトリの直下で次を実行すると `index.html` が作り直されます。

```
python3 src/build.py
```
